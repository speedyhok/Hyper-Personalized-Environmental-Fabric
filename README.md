# Hyper-Personalized Sensory Environment Fabric (H-SEF)

An automated, closed-loop biophysical pipeline that optimizes environmental lighting, sound, and olfactory parameters in real time based on user cognitive workload, stress levels, and affective states.

## Key Features
* **Real-time Closed-loop Biophysical Pipeline**: Processes streamed smartwatch metrics (HR, HRV, GSR) and simulated EEG signals.
* **Cognitive State Modeling (CSM)**: LSTM network predicts future user valence, arousal, and cognitive workload.
* **Continuous Generative Sensory Synthesis**: Automatically maps affective states to optimal binaural frequencies, light spectrums (CCT & Lux), and scent dispersion targets.
* **Interactive 3D Sensory Room**: Real-time Three.js visualization showing instantaneous lighting and scent mist adaptations.
* **Actuator Integration**: Philips Hue and Home Assistant endpoints for physical room control with automated safety locks.
